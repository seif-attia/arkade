
# Arkade++

Arkade++ is a minigame center that has 5 minigames:

- TicTacToe
- DuckInvaders (Similar to classic space invaders)
- Snake
- Tetris
- Arcade Car Racing


# Install

- For windows: Just download the zip file from the releases and play right away

- Linux / Mac: Clone the repo and build the project yourself.
__Dependecies for building:__
- Raylib
- make / cmake (Have to create your own config or use Visual Studio if its avaliable)



## Controls
__Tetris__

- Left and right arrow keys for movement
- Up arrow key for rotating blocks
- Down arrow key for moving blocks down faster (will give you extra score)
- Enter to restart upon losing


__Duck Invaders__

- A & D or Left and Right arrow keys for movement
- Space to shoot
- Enter to restart

__Snake__

- Arrow keys for movement
  
__Car Racing__
- Arrow Keys for movement or mouse
